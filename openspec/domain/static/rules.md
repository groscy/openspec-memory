### Rule: index-never-hand-edited
`_index.yaml` must never be edited manually — it is always regenerated by `/opsx:domain sync` or `/opsx:archive`.

### Rule: tasks-required-before-apply
A change must have a completed `tasks` artifact before `/opsx:apply` can run.

### Rule: domain-loaded-on-entry
Every skill must check for `openspec/domain/` and load `_index.yaml` at the very start of execution when the directory exists.

### Rule: concept-files-by-name-only
Skills must load individual concept files only when the concept name appears in the current change or task scope — never load all concept files by default.

### Rule: discoveries-default-active
Newly captured discoveries must always be written with `status: active`.
