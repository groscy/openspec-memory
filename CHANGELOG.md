# Changelog

## Unreleased

### Breaking Changes

- **`.claude/commands/opsx/` is now generated output.** The canonical source for all OpenSpec skills has moved to `openspec/skills/<name>/SKILL.md`. The `.claude/commands/opsx/` adapter files are regenerated by running `openspec install skills --env claude`. Do not edit adapter files directly — changes will be overwritten on the next install.

### Added

- `openspec/skills/` — vendor-neutral directory for all OpenSpec skill files. Each skill is stored as `openspec/skills/<name>/SKILL.md` with an agent-agnostic frontmatter block (`name`, `description`, `triggers`, `agents`, optional `args` and `version`).
- `openspec install skills [--env <claude|copilot|intellij|all>]` — new CLI subcommand that generates per-environment adapter files from the portable skill sources.
- `openspec migrate skills` — new CLI subcommand that converts existing `.claude/commands/opsx/*.md` files into `openspec/skills/<name>/SKILL.md` format with generated frontmatter, then runs install automatically.
- Copilot adapter output at `.github/copilot-instructions/<name>.md` — enables skill invocation from GitHub Copilot Chat.
- IntelliJ run configuration output at `.idea/runConfigurations/opsx_<name>.xml` — surfaces skills in the JetBrains Run menu.
- OpenSpec IntelliJ plugin gains a `SkillLoader` that reads `openspec/skills/` at project open and registers skills as IDE actions.

### Migration Guide

If you have an existing project with hand-edited `.claude/commands/opsx/` files:

1. Run `openspec migrate skills` — this reads your existing command files and creates `openspec/skills/<name>/SKILL.md` for each, preserving the prose body and adding generated frontmatter.
2. Review the generated frontmatter (especially the `agents` field) and adjust as needed.
3. Run `openspec install skills --env all` to regenerate all adapter files.
4. The original `.claude/commands/opsx/` files are left untouched by migration. Remove them once you have verified the new adapters work correctly.

To roll back: restore `.claude/commands/opsx/` from git history. The skill content is preserved — no data loss.
